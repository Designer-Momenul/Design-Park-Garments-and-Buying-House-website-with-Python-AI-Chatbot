# Design Park Garment - Corporate Website & AI Assistant

A modern, responsive corporate website for **Design Park Garment**, a garments sourcing and buying house. This project showcases garment manufacturing capabilities, product collections, and features an integrated **AI Customer Support Chatbot** to assist buyers with instant inquiries.

## Key Features
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices using modern CSS techniques.
- **Integrated AI Chatbot:** Interactive virtual assistant built to answer buyer queries regarding product catalogs, minimum order quantities (MOQ), lead times, and sourcing services.
- **Product Showcase:** Dedicated sections highlighting knitwear, woven garments, sweaters, and quality assurance standards.
- **Company Profile & Services:** Clear overview of end-to-end apparel sourcing, merchandising, and compliance standards.
- **Interactive UI:** Smooth scrolling, clean navigation, and inquiry contact forms built with vanilla JavaScript.

## Setup & Local Installation
To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/design-park-garment.git
   ```
2. Navigate to the project directory:
   ```bash
   cd design-park-garment
   ```
3. Open `index.html` directly in your web browser, or use a local development server such as the **Live Server** extension in VS Code.

## Security Note
If you connect this chatbot to an external LLM API, ensure your API keys are stored securely on a backend server or via environment variables rather than exposing them directly in client-side JavaScript files.
